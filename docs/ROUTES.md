# API routes

Generated by `npx tsx scripts/gen-platform-docs.mts`. Every POST takes JSON from the site's own origin, is rate-limited per address and validated with a schema (16 KB unless noted in the route). *Signed in* routes answer 401 without a session; admin routes answer 401/403 without the permission, and 401 `reauth` when a fresh code is needed. Other people's records answer 404. See [api.md](api.md) for the public form routes and response codes, and [PERMISSIONS.md](PERMISSIONS.md) for roles.
