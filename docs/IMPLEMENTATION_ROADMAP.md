# Roadmap

## Done in this rebuild

- Repository audit, competitor research, migration branch
- Design system, light and dark themes, original character set
- 36 state and UT profiles, 52 destination guides, map, search and filters
- Trip planner with editing, route map, estimates, calendar, print, share, packing and expense splitting
- Festivals, food and recipes, heritage, art and traditions
- Bookings, services, gallery, stories, about, contact, legal pages
- Forms API, MongoDB persistence, rate limiting, security headers
- Unit, security and browser tests

## Before going public

1. Resolve the owner decisions in `PROJECT_STATUS.md`
2. Human fact-check of time-sensitive content, starting with permits, closures and security advice
3. Create MongoDB Atlas and Vercel projects, and run the release checklist in `setup.md`

## Next, in priority order

1. Add confirmed 2027 festival dates from official lists
2. Add official links once the portals that failed during research can be confirmed
3. Add more guides per state; most states and UTs currently have one or two
4. Add licensed travel video to the gallery
5. Add a Lighthouse budget to CI
6. Optional accounts, so saved trips sync across devices, using a trusted auth provider
7. A lightweight CMS, if non-developers will edit guides
8. Hindi and other Indian-language versions
