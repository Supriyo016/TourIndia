# Permissions

Generated by `npx tsx scripts/gen-platform-docs.mts` from `src/features/admin/permissions.ts` and the admin pages and routes. Every admin page and API checks its permission on the server; the menu only hides what a role can't use. Every admin also needs an authenticator code at sign-in, and actions marked *fresh* ask for one again if the last was over 15 minutes ago. `ADMIN_EMAILS` are always Super Admins.
