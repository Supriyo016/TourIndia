# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Supriyo016/TourIndia/security/advisories/new),
not in a public issue. Include the affected URL or file, steps to reproduce and the impact you expect.

You should get a reply within a week. Fixes are deployed from `master`, so only the live site is supported.

How the site protects itself (headers, CSP, rate limits, sessions, validation) is described in
[docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md).
